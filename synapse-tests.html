Week 01 — Simulations

Synaptic Input Tests

First synaptic input tests for the CA1 pyramidal neuron model (ModelDB 2018009, Migliore et al. 2018). The base model is a pure intrinsic channel model with no built-in synapses, so synapses are added from scratch.

All synapses use NEURON's built-in Exp2Syn mechanism — the standard event-driven AMPA/GABA synapse. Excitatory synapses use reversal potential e = 0 mV (AMPA-like); inhibitory synapses use e = −75 mV (GABA-like). Presynaptic activity is delivered by NetStim objects through NetCon. All parameter values are taken from the project parameter table.

Tests
Test 01 — Single Excitatory Synapse

Clean EPSP

One Exp2Syn synapse on an apical dendrite with CA3 proximal parameters, driven by a NetStim at 10 Hz. Produces a clean excitatory postsynaptic potential at the soma. Confirms the full pipeline: load cell, attach synapse, connect NetStim, record, plot.

Test 02 — Excitatory vs Inhibitory

EPSP vs IPSP

Adds an inhibitory synapse on the soma (PV basket parameters, e = −75 mV) alongside the excitatory one. Excitatory input depolarizes the membrane (EPSP, upward); inhibitory input hyperpolarizes it (IPSP, downward below rest). Same Exp2Syn mechanism, different reversal potential.

Test 04 — Random Distribution (Baseline)

Distributed Synaptic Input

Two functions randomly distribute synapses across the apical and basal dendrites — one for excitatory, one for inhibitory — at the 10% baseline count (180 excitatory + 18 inhibitory). The cell integrates the distributed input and fires a sustained train of action potentials.

Test 05 — Conductance Scaling

Effect of Synaptic Strength

Keeps the synapse count fixed (180/18) and varies the excitatory conductance peak (0.5×, 1×, 2× the table value) with identical random placement each run. Firing scales with conductance — roughly 17 / 28 / 57 spikes for low / baseline / high — isolating synaptic strength from synapse number.

Note on synapse mechanisms

Dedicated AMPA/GABA .mod files were investigated. The available simple ones either required separate include files, or — in the case of the CA1-specific Lupascu/BBP GABA file — included stochastic release, short-term plasticity, and GABA-B, all of which are excluded from this baseline.

Their core conductance is the same dual-exponential profile as Exp2Syn. Dedicated mechanisms will be revisited when plasticity and NMDA are added before the seizure experiments.
